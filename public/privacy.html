Privacy Policy

Last changed 25 October 2026

Shrinking Room is a small puzzle game. It stores what it needs to keep your progress and nothing else. There is no analytics, no advertising, no tracking pixel, and no third-party script on any page.

If you create an account

The server stores three things:

Your username. Stored in lowercase, 3 to 24 characters of letters, numbers, and underscores. No email address is asked for or stored.

A password hash. Your password is hashed with bcrypt. The password itself is never written to the database and never logged.

Your progress. Best times per room, which room you have unlocked, difficulty, sound and motion settings, and three counters: puzzles solved, rooms cleared, best streak.

That is the whole table. There is no profile, no avatar, no location, no device fingerprint.

The session cookie

Signing in sets one cookie named sr_session. It holds a signed token that identifies your account, is readable only by the server (httpOnly), lasts 30 days, and is sent only with requests to this site. Signing out clears it.

If you play as a guest

Guest progress is saved in your own browser's local storage under the key sr_guest_progress_v1. It is never sent to the server. If you later create an account, you can choose to carry over your chapter one best times; that is the only moment guest data leaves the browser, and the server accepts only chapter one rooms with plausible times.

What is not collected

No email, no real name, no birth date, no payment details, no advertising identifiers, no cross-site cookies, no fonts or scripts loaded from another domain. The typefaces are served from this server.

Logs

The application writes errors to its own server log so that breakage can be diagnosed. Error logs contain the request path and the error, never a password. If the game is hosted on a platform, that platform may keep its own short-lived request logs, which this project does not control.

Removing your data

There is no delete button yet. Ask in the project repository and your account row, including its progress, will be removed by hand.

Changes

If what the game stores changes, this page changes with it and the date at the top moves.
